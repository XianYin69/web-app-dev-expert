# 知识树（Web 应用工程）

拓扑根：应用层契约与服务端保证。九叶不可再分：每叶对应一类「服务端必须保证」的问题，
跨叶问题按「契约 → 实现 → 交付」顺序归位。索引见 [asset](../asset/asset.md)，
机器可读形式见 [knowledge_tree.json](../asset/knowledge_tree.json)。


## 叶间边（causal）

- 1 → 2：缓存语义决定 API 可被哪一层中间节点缓存。
- 2 → 6：契约形状决定查询与分页实现。
- 3 → 4：身份机制决定攻击面与响应头策略。
- 4 → 8：日志脱敏是安全约束在可观测层的落点。
- 5 → 9：渲染模型决定首屏预算与 hydration 成本。
- 6 → 7：迁移与队列共享「幂等 + 可回滚」前提。
- 7 → 8：饱和指标驱动限流与自动扩缩。
- 8 → 9：发布指标是性能预算回归的判定依据。

## 边界（不再向下的方向）

视觉/交互设计、浏览器框架实操、接口契约设计、端到端自动化测试、数据库内核调优、
并发模型证明、语言级代码审查 —— 均移交兄弟技能，见
[dependence](../dependence/dependence.md)。知识树到此不可再拓扑出新领域。
